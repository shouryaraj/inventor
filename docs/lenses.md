# Lenses: how an inventor reads a piece of text

Inventor's extraction prompt encodes a set of observation habits that writers on invention
and design describe. They are distilled here into lenses a model can apply to text. Each
problem found is tagged with the lenses that apply.

| Lens | Looks for | Where the habit comes from |
|---|---|---|
| `friction` | small, recurring annoyances people tolerate | keeping a log of annoyances; *The Innovator's DNA* (Dyer, Gregersen, Christensen): observing |
| `workaround` | home-made fixes: scripts, spreadsheets, manual steps | the same: workarounds reveal unmet needs |
| `doesnt_work` | tools or methods that fail in practice | innovators become sensitised to what doesn't work |
| `unmet_need` | "is there a tool that…", requests for things that don't exist | questioning and observing |
| `limitation_future_work` | limitations and open problems stated by researchers | the adjacent possible (Steven Johnson, *Where Good Ideas Come From*) |
| `norman_affordance`, `norman_signifier`, `norman_constraint`, `norman_mapping`, `norman_feedback`, `norman_conceptual_model` | design failures in everyday tools | Don Norman, *The Design of Everyday Things* |
| `questioned_default` | an assumption everyone accepts that the text challenges | "question the default" |
| `already_changing` | a shift already under way that creates new problems | innovators notice changes that have already begun |

## Habits that map to later pipeline stages

| Habit | Stage |
|---|---|
| Observe; describe what is there, not your interpretation | extract: one plain statement, no solutions, verbatim quote |
| Associate ideas across unrelated fields; exaptation | associate (planned): cross-domain analogies, labelled hypotheses |
| Slow hunches; keep a commonplace book | notes (planned): one note per problem that accumulates evidence across runs |
| Network with people outside your field | the report's last step is human: talk to the people quoted |
| Experiment; prototypes as thinking tools | out of scope for the tool; the report ends where building begins |

The lens definitions are paraphrases, not quotations, and the tool makes no claim that these
authors endorse it.
